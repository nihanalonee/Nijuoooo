## What's inside

| Module | What you can do |
|---|---|
| 💠 **DEX & Markets (AMM)** | Real constant-product swaps with fees, congestion slippage and gas. Trade 5 launch tokens, meme-coin minting, equity exchange with live IPOs. |
| 🧪 **Crypto Lab** | Mint your own token, seed/exit liquidity, stake for yield, **flash-loan attacks** (front-runnable!), rug your own pool into dirty cash. |
| 🌐 **City & ISP Backbone** | Lay fiber across districts, host server racks, mine crypto. Congestion moves gas fees; outages kill your hash rate. Buy property — crime and sentiment move valuations. |
| 🏦 **Banking** | Charter a bank: fractional reserves, deposit-rate economics, predatory vs. secured underwriting, loan defaults, bank **runs** and catastrophic collapse with government bailouts. |
| 📺 **Media Empire** | Greenlight & air shows, grow reach for ad revenue, shill your bags on air, run **investigative exposés** or outright fake-news campaigns — with FCC blowback. |
| 💀 **Underworld** | Launder dirty cash, retain hacker crews, corporate heists, smuggling lanes, bribe officials (some wear wires). |
| 🏛️ **Government** | Living Senate: tax rates, scheduled law docket, lobbying (and stings), warrants on your heat, bailouts. |
| 📡 **The Wire** | Server-wide social feed generated by the simulation itself — pumps, scandals, IPO bells, OCU leaks. |
| 🤖 **Autonomous rivals** | Six AI masterminds (whales, media barons, the cartel, the reform senator) run their own agendas every tick: accumulating, dumping, smearing, hacking *you*, founding companies. |
| 🔥 **God Protocol** | Server admin terminal if the profile email is `mirajx132@gmail.com` (per master spec §8): spawn trillions, `pump`/`crash` any market, `smite` rivals, force votes, `wipe` the world. Try `help`. |

## Systems notes

- **World Engine** — the "Dungeon Master" layer (`js/world.js`) reads live server state
  (sentiment, congestion, your bank size, open warrants) and orchestrates macro events:
  *Global Supply Chain Collapse*, *Regulatory Crackdown*, *AI Tech Boom*, *City Blackout*, whale drama…
- **Persistence** — autosaves every few ticks to `localStorage`; *New* reboots the world.
- **Speed control** — pause / 1× / 2× / 4× simulation speed.

### Architecture

```
index.html            shell (login + app layout)
styles.css            dark neon terminal-tycoon theme
js/
  main.js             boot, login, heartbeat tick loop, action delegation, autosave
  state.js            world model: districts, tokens, rivals, laws + save/load
  market.js           AMM DEX, staking, rug/flash ops, stocks, world-engine price tick
  city.js             real estate, fiber/racks/mining/uptime, banking & bank runs
  media.js            networks, shows, propaganda, smears, FCC
  npcs.js             rival masterminds' autonomous decision engine
  world.js            macro events, Senate laws, warrants, bailouts
  actions.js          player crime ops & toggles
  god.js              admin command interpreter
  ui.js               all panels, charts, focus-preserving re-render
```

Run locally with any static server (ES modules need http):

```bash
python3 -m http.server 3002   # then open http://localhost:3002
```
